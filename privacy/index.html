Privacy

Every tool runs in your browser. What you type, paste, generate or convert never leaves your device. If you allow it, we count how the tools are used so we know which ones to improve and which ones nobody needs.

Accept allThe same events, plus a random visitor id so we can see whether people come back and which tools they use together. Google ads are also loaded (see below).Your choice, the session id, the random visitor id, and Google’s advertising cookies.

Nothing is sent before you choose. You can change your mind at any time from the “Privacy choices” link at the bottom of every page; switching to Reject or Essential only deletes the visitor id from your browser.

What a usage event contains

  • Which page was opened and which tool was used.
  • Which options were picked (for example a unit pair, a text case, a password length).
  • Which buttons were pressed (for example Copy, Format, Encode) and whether the tool showed an error.
  • How long the page was visible.
  • A rough device class: mobile, tablet or desktop.

What we never collect

  • Anything you type, paste or get back from a tool: text, JSON, passwords, URLs, colours, dates.
  • Your name, email or any account. There are no accounts.
  • Your IP address, browser fingerprint or user agent. Our code never stores them; the only device detail is mobile, tablet or desktop.
  • Data for anyone else. There are no third-party analytics scripts. The only third party is Google AdSense, and only if you choose Accept all.

Ads

The site is kept free by Google AdSense. The ad script is loaded only after you choose Accept all. With no choice, Essential only or Reject, your browser never contacts Google’s ad servers. When it is loaded, Google may set cookies and use them to show and measure ads; that is governed by Google’s advertising policy, not by us. Ads never see what you type into a tool. If you later switch to Essential only or Reject, ads stop from the next page you open; Google’s cookies can be cleared in your browser settings.

Where it goes and for how long

Events go to a small first-party function on this site and are stored in the site’s own storage on Netlify, our host. Raw events are deleted after 90 days. We keep only aggregated counts, such as “Word Counter was used 120 times this week”.

Suggestions

The suggestion form is separate from the choices above: it sends only what you write in it, plus the kind of suggestion and the tool it is about. Please leave personal details out. Suggestions are read by the people deciding what to build next.

The code

The site is open source. You can read exactly what is sent in scripts/build.py and netlify/lib/core.mjs.

Help us decide which tools to improve?

We would like to count which tools, options and buttons get used, and for how long. What you type and the results stay on your device — we never see them. How this works

Essential only: anonymous counts, no ID kept between visits. Accept all: adds a random ID so we can tell when you come back, and shows Google ads, which use cookies. Reject: nothing is sent.
